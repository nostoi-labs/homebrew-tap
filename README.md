# Nostoi Homebrew tap

```
brew install nostoi-labs/tap/livecli                  # the live command (MIT)
brew install --cask nostoi-labs/tap/reference-probe   # probe plugin, open source (MIT)
brew install --cask nostoi-labs/tap/loudline-probe    # probe plugin, freeware
```

[LiveCLI](https://github.com/nostoi-labs/livecli) is a command line for Ableton Live built for AI agents. After installing it, run `live setup` and choose LiveCLI as a Control Surface in Live.

The probe plugins are VST3 for Apple Silicon Macs. Install them with Live closed, then rescan plug-ins in Live.
